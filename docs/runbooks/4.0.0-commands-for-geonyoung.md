## Rollback (R), before step 11
```sh
sudo tailscale serve --https=443 off
sudo launchctl bootout system/com.llmserving.gateway
sudo mv /Library/LaunchDaemons/com.llmserving.gateway.plist /opt/eve-gw/etc/daemon.plist.disabled
sudo install -o $(id -un) -g staff -m 0600 /var/root/eve-rollback/com.llmserving.gateway.plist ~/Library/LaunchAgents/com.llmserving.gateway.plist
cp -p ~/llm-serving/bin/gateway.v3.1.0.bak ~/llm-serving/bin/gateway                 # no sudo
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.llmserving.gateway.plist  # no sudo
sudo tailscale serve --bg --https=443 http://127.0.0.1:8000
curl -s 127.0.0.1:8000/health                                                         # "version":"3.1.0"
```
This takes about 2 minutes and needs no DB change (3.1.0 ignores the session tables). It reopens the HIGH. After step 11, first put the rotated
DB URL and key into the restored plist and `.api_key`. If step 8 was done, also run
`sudo cp -p /etc/pf.conf.pre-eve /etc/pf.conf && sudo pfctl -f /etc/pf.conf`.
