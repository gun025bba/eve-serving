## 4. 제안

1. 자동 도구 선택은 **프롬프트만으로 두지 말고 V4식 게이트(한 단어 분류)를 게이트웨이에서 강제**해요. 프롬프트 단독은 H 80%, C 27~33%예요.
2. 결정 라운드는 `chat_template_kwargs.enable_thinking=false`로 고정해요(정확도 차이 없이 6배 빨라요).
3. 도구 목록은 라운드 간 바꾸지 않아요(캐시 재계산 비용).
4. 도구 결과는 토큰 상한(약 4k 토큰)으로 자르고, 메모리 주입은 1,500자 이내로 시작해요(1,500자 +2.4초, 3,000자 +4.6초 prefill).
5. 임계값은 V4를 3시드로 돌린 뒤에 확정해요.
